What the analysis suggests

Risk segmentationDefault incidence rises across designed A–E tiers. Review pricing and loss together; score rank is not policy.
Vintage contextMonthly outcomes are noisy in smaller cohorts. Real vintages need seasoning and censoring controls.
Decision economicsA 50% threshold is illustrative only. Real cutoffs need loss severity, funding cost, and customer impact.

Reproducibility & responsible use

Rebuild the project

Run python src/credit_risk.py from the project folder. The seeded pipeline regenerates data, portfolio cuts, validation files, and this standalone dashboard.

NumPy and pandas only · no external dashboard assets or network calls.

Fictional data only. Relationships are intentionally designed. Results do not represent lender performance or support approvals, declines, pricing, provisioning, fairness, or compliance claims. Real use requires representative data, independent validation, legal and subgroup review, decision-cost analysis, governance, and monitoring.
